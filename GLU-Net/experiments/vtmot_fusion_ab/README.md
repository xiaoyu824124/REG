## A/B 设计

本实验借鉴 [UniVF](https://papers.nips.cc/paper_files/paper/2025/file/baaa7b5b5bbaadca5023e1ab909b8af5-Paper-Conference.pdf) 使用多帧特征与光流对齐的思想；它不是 UniVF 原模型复现。

- **A：逐帧融合。** 冻结的配准模型把当前红外帧变换到当前可见光坐标。轻量双编码器从当前红外灰度与可见光亮度提取特征，预测融合亮度；可见光色度保留。
- **B：三帧融合。** 使用与 A 同一双编码器和融合解码器。前后帧的红外、可见光特征分别由**同模态**当前帧到邻帧的 128 网格光流对齐。前后向光流不一致（>1.5 个 128 网格像素）、越界及红外配准无效位置全部遮挡。两模态分别聚合后才进入当前帧融合头。额外时间特征更新层的末层初始化为零，故 B 训练前逐像素复现 A。

两组从相同随机初始化开始，训练相同 38 条序列、相同帧顺序与更新数。每轮按步长 5 选择一个相位，20 轮共四次覆盖全部训练帧；每组 15,200 次优化更新，批量 2、AdamW 初始学习率 `1e-4`、余弦调度。两组都只用**相同空间损失**：有效区域亮度目标 L1 + 2 倍 Sobel 梯度 L1 + 0.5 倍红外高亮不足惩罚。训练不使用 GT flow、`visible_gt`、关键帧策略或时间一致性损失。以完整四条验证序列的平均空间损失选各组最佳轮，完成训练后再做视频指标比较；锁定测试序列不参与选择。

固定验证指标为：空间损失、融合图输入边缘保留率、梯度幅度比、热目标保留率、没有任何输入边缘支持的融合边缘比例（重影代理），以及在 128 网格位移 ≥1.5px 的运动区域内单独计算的重影比例；时序指标为用当前到前帧的可见光域光流对齐前一融合帧后的有效区域 L1 和 SSIM。边缘采用固定 Canny 阈值 75/150，允许 2px 邻域；热目标定义为有效区域内红外亮度 >0.6 且高于可见光亮度 0.1，保留定义为融合亮度 ≥该红外亮度的 90%。另保存预先固定的困难帧图像。计时包含每帧冻结配准网络与 warp、B 的前后两邻帧及两种模态的前后向 128 网格 Farneback 位移估计（内部帧每帧八次估计）以及融合前向；两组都排除磁盘 I/O 和指标计算。训练缓存只是避免每轮重复配准和光流计算，报告的 B 推理耗时仍计入这两部分。

**预先固定的采用规则：**B 在相同 800 帧上空间损失和时间对齐 L1 都低于 A，至少 500/800 帧空间损失改善；输入边缘保留率下降不超过 0.01、梯度幅度比下降不超过 0.02、热目标保留率下降不超过 0.01、全局及运动区域的无支持边缘比例均上升不超过 0.01。若仅时间一致性提高但画面模糊、热目标变弱或重影增多，则不采用 B。下一轮才允许单独测试遮挡掩码时间损失。
