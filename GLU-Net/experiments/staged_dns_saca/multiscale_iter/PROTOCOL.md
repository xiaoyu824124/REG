# 两尺度局部迭代细化：验证协议

参考 CRFT 按当前 flow 对齐源特征、比较两侧特征、预测残差、再次对齐的循环。本分支不实现 CRFT 整网或其 SGT、CENet、置信度平滑，也不加入 MIND。

固定原始第 37 轮 best_coarse.pth，冻结 VGG、DNS、SA/CA、全局相关、旧局部解码器、单次 DCN 和 flow 上采样层。真实 512 输入的 flow 网格为 16、32、64、128。64、128 网格的 VGG 特征通道数为 256、128；一格分别相当于 512 图像中的 8px、4px。全部 flow 用 512 图像像素单位，按 VI 目标坐标加 flow 采样 IR 源特征。64 网格两轮共享权重更新，增量传至冻结 128 flow 后再两轮共享更新。残差头零初始化。

两组使用 train176/val23、相同原粗权重、batch2、种子2026、相同图像顺序及最多五轮 440 次优化更新。按验证集最终 512px EPE 与 min_delta=0.01 选权。DCN-only 最佳是原细阶段第 1 轮，其候选训练仍可运行到同样的 440 步。新分支主损失与 DCN-only 一样为最终 512px Charbonnier EPE，另有 0.1 权重的四轮中间 flow 监督；因此损失并非完全相同，报告时需说明。

报告各轮 64/128 EPE（统一换算 512px）、最终 EPE、逐图改善、GT 位移 ≥64px 区域、首个 32 网格相关窗口内外、时间和峰值显存。窗口半径为 32 网格每轴四格，即 512 图像中每轴 64px。测试集 22 对不能用于选模型。

本地仅完成编译、真实尺寸、合成平移方向、零初始化、两张训练图的一步反传和一张验证图的接口检查。初始化 64/128/final 输出与冻结模型最大差均为零；一步梯度非零、冻结基础模型变化为零。完整 440 步对照由服务器运行，目前没有多尺度分支的训练后验证结果。

服务器运行命令见最终回复；输出目录须为空。完整运行会生成 history.json、best_iter_branch.pth、per_image_val.csv、report_val.json，且不会覆盖原权重。
