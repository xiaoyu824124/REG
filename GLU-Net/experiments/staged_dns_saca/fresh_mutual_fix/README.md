# 从基础预训练权重重新训练粗、细配准

roadscene_staged_mutual_fix.py 是独立配方。它不接第 37 或 45 轮权重，而从相同的 GLU-Net 基础预训练权重初始化 DNS+SA/CA、粗 flow 解码器和既有局部网络。唯一匹配计算变化：进入原 MutualMatching 前，对相关值执行 clamp_min(0)。全零相关输入已检查为有限的零输出。

阶段一沿现有配方只训练 VGG level_4、DNS、SA/CA 和粗解码器。最多 200 轮，验证粗 EPE 选权，patience=20、min_delta=0.01。阶段二从本次 best_coarse.pth 开始，冻结粗网络及 BN 统计；前 5 轮只训练单次 32 网格 DCN，之后训练旧局部层与 DCN。预训练 flow 上采样层冻结。最多 80 轮，验证最终 512px EPE 选权，patience=12、min_delta=0.01。沿用原损失、数据划分和评测器，不启动联合训练，也不读取 22 对独立测试图像。

服务器先在一个独立目录依次完成粗、细的 code-check，再换新的空目录正式训练。两阶段命令均须使用相同 output 路径；具体命令见交付回复。训练中断后在对应阶段命令末尾加 --resume，会核对基础权重、脚本哈希、预算和检查点来源。不能混用旧实验目录。

本地只跑了两对训练图像、一对验证图像的代码检查：粗阶段第 1 轮完成两次更新，细阶段第 2 轮完成累计六次更新；两阶段均能评测并保存带修复标记的检查点，细阶段父 SHA 与此次粗权重相符。代码检查 EPE 不代表 23 对验证集成绩。完整训练结果待服务器运行。
